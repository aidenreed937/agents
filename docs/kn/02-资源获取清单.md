---

## 推理策略(已锁定)

| 环节 | 跑哪 | 理由 |
|---|---|---|
| Embedding(小模型,常跑) | **本地** `bge-m3` | 小、快、带得动,省额度 |
| LLM 生成(吃内存) | **GLM 免费 API 优先** | 把 16GB 留给 Docker/IDE/浏览器;想要工程体感再本地 `qwen2.5:7b` |
| 推理模型体验(最重) | `deepseek-r1:1.5b` 或 API | 别本地跑 r1:7b |
| Rerank(重 cross-encoder) | **免费 API** | 16GB 再叠 2GB+ 模型太紧 |

本地↔API 在代码里只差一个 `base_url`,随时无缝切,学的东西零差别。

## 【立即执行】现在就能一次性拉全(A 档)

**GitHub 仓库**(建议建 `refs/` 目录统一放;全程教程/题库主力):
```bash
mkdir -p refs && cd refs
git clone https://github.com/adongwanai/AgentGuide                                 # W1 路线 + W5/7/8 题库
git clone https://github.com/datawhalechina/prompt-engineering-for-developers      # W2 Prompt(吴恩达中文版)
git clone https://github.com/datawhalechina/all-in-rag                             # W3-4 RAG 主力(10章)
git clone https://github.com/datawhalechina/hello-agents                           # W3 RAG理论 / W5 Agent / W6 LangGraph / W8 面经
git clone https://github.com/liyupi/yu-ai-agent                                    # W6 架构参考(只借鉴,业务换)
git clone https://github.com/wdndev/llm_interview_note                             # W7 手撕参考(需核实)
git clone https://github.com/jurnea/LangGraph-Chinese                              # W6 备用(社区翻译)
cd ..
```

**工具 + 模型 + 作品仓库**:
```bash
brew install ollama
ollama pull qwen2.5:7b           # W1 主力(4.7GB,带得动)
ollama pull deepseek-r1:1.5b     # W1 体验推理(替代 7b,~1.1GB)
ollama pull bge-m3               # W3 embedding(~1.2GB)
docker run -d --name pgvector -e POSTGRES_PASSWORD=postgres \
  -p 5432:5432 pgvector/pgvector:pg16
gh repo create ai-agent-portfolio --public
```

**Python 包**(随项目 `uv add`,无需一次装全):
| 周 | 命令 |
|---|---|
| W2 | `uv add openai pydantic jupyter` |
| W3 | `uv add langchain langchain-postgres langchain-openai "psycopg[binary]"` |
| W4 | `uv add streamlit` |
| W5 | `uv add mcp` |
| W6 | `uv add langgraph` |
| W7 | `uv add numpy`(手撕够用;`torch` 可选,M1 走 MPS) |

> 磁盘核算:7 个仓库 + 三个模型(~7GB)+ docker 镜像(~1GB)+ torch(可选 ~1.5GB)≈ 10-12GB,你有 107GB,无压力。

## 成本结算

- **现金 ¥0 可行**:本地全免费 + GLM/硅基流动免费额度 + 文档免费 + 博客/Pages/招聘免费。
- **唯一可选**:¥20-50 API 备胎(D 档),大概率用不上。
- **被你省掉的钱**:租 GPU 的 ¥300-500(E 档,根本不需要)。

**最易获取 → 最需折腾** 排序:A(一行命令拉全)> B(收藏)> C(注册拿 key)> D(充值)> E(别碰)。
