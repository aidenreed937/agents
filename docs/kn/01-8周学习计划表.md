> 时间窗口：2026 年 6 月起，目标 8-10 周拿 offer（提前批窗口，竞争比 8-9 月低 30-40%）

## 零、开局必读：路线总原则

**黄金技能顺序（别跑偏）：**
`Python 速成 → Prompt Engineering → RAG → Agent 核心 → 作品打磨 → 简历投递 + 面试突击`

**现在坚决不要碰（应用岗 ROI 极低，碰了就是浪费窗口期）：**

| 不要碰 | 原因 |
|---|---|
| LoRA / SFT 微调 | 60K+ 高端岗才要，是算法线门槛，先放弃 |
| Transformer 源码逐行精读 | 八股层面理解即可，不需要从零实现训练 |
| RLHF / DPO 对齐训练 | 算法/对齐线专属，开发岗几乎不问实操 |
| 预训练 / 分布式训练 | 完全不在应用岗射程内 |
| 一上来就堆框架（LangChain 全家桶背 API） | 报告明确：仅 12.4% JD 硬要求开源框架，框架不是门槛，判断力才是 |

**贯穿全程的三条主线（每周都在推进）：**
1. **补 Python**（主语言短板，硬通货，前 2 周集中突破，之后在项目中持续用）
2. **做作品**（从 Week 3 开始动手，不是学完才做；HC:投递≈1:200，作品是唯一破局点）
3. **攒面试弹药**（八股/手撕/算法从 Week 1 起每天碎片时间积累，Week 7-8 集中突击）

**两个利用 Java/TS 底子的杠杆：**
- 用 **Spring AI / LangChain4j** 快速建立 Agent/RAG 直觉（你能秒懂），但**主线产出必须是 Python + LangChain/LangGraph**——JD 里 Python 提及 125 次 vs TS 15 次，简历主语言必须是 Python。
- 简历差异化：用「后端下水道能力」（接口抽象、状态机、容错降级、权限控制、并发调度）讲 Agent 工程化，这是你碾压应届/转码者的护城河。

**本地环境（一次性装好，全程复用）：**
- 模型运行：[Ollama](https://ollama.com/) 跑 `qwen2.5:7b` + `deepseek-r1:7b`（各约 4.7GB，16GB 内存可跑；内存紧张退到 3b）
- 向量库：**Pgvector 起步**（最简单，复用你的 SQL/PG 经验），进阶再碰 Milvus/Qdrant
- 语言：Python 3.11+（用 `uv` 或 `conda` 管虚拟环境）
- Embedding：本地 `nomic-embed-text` / `bge-m3`（Ollama 拉取），或 API（如有）

> 重要技术提示（避坑）：LangChain v1.0（2025-10）已**弃用** `langchain_community.PGVector`，新项目请用 [`langchain-postgres`](https://python.langchain.ac.cn/docs/integrations/vectorstores/pgvector/) 包 + `psycopg3`，连接串用 `postgresql+psycopg://...`（不是 `psycopg2`）。教程里看到老写法要自觉迁移。

## 二、每日时间分配建议（在职备战）

### 工作日（1-2h，建议 1.5h）
| 时段 | 时长 | 安排 |
|---|---|---|
| 早通勤/午休 | 20-30min | 碎片：刷 3-5 道八股 / 看 1 道手撕题 / 背 1 个概念 |
| 晚上主攻 | 60-90min | 当周主线任务（学 + 动手写代码，**必须动手，不许只看视频**） |
| 睡前 | 10min | 当日 commit + 记一条"今天学到的最重要的点" |

### 周末（每天 4-6h，建议两天共 10-12h）
| 模块 | 时长 | 安排 |
|---|---|---|
| 作品集冲刺 | 4-5h | 当周作品的核心开发（整块时间做项目，工作日难有连续块） |
| 系统学习 | 2-3h | 补当周教程没看完的章节、做对比实验 |
| 面试突击 | 2h | DP 算法 2-3 题 + 八股错题本二刷 |
| 复盘 | 0.5h | 对照本周"验收标准"打钩，没达标的下周补 |

### 铁律（来自报告一手教训）
1. **绝不走马观花**：视频不快进，每个例子必须亲手复现跑通（800 份投递仅 2 面的人，死在"看了没做"）。
2. **做项目优先于学全**：W3 起每周都有产出物，宁可项目糙一点先跑通，再回头补理论。
3. **能讲透 > 学得多**：每个作品都要能讲清"为什么这么设计、踩了什么坑、结果怎么量化"。
4. **每天 commit**：GitHub 绿墙是最低成本的"在认真转型"的证据。
5. **优先现公司落地**：8 周中若能在现职推动一个 Agent 落地，立刻去做——企业项目背书 > 任何个人项目。
