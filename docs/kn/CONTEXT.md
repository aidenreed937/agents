# AI Agent 求职备战(8 周计划)

个人学习工作区:目标 8-10 周内从「10 年全栈 / Android」切入「模型应用工程师 / AI Coding 工程师」。本文件是术语表,统一我们讨论资源、成本、技术选型时的语言,不放实现细节。

## Language

### 岗位与能力层

**应用层**:
本计划的求职目标层 —— RAG、Agent 编排、Prompt、工程化。大模型在此只是「一个被 HTTP 调用的推理端点」,不关心其内部权重。
_Avoid_: 应用岗(口语可,术语统一用「应用层」)

**训练层**:
模型权重的训练 / 微调 —— LoRA、SFT、预训练、RLHF、分布式训练。计划开篇明令**不碰**:属算法 / 对齐线门槛,应用岗几乎不问实操。
_Avoid_: 算法层(近义,本计划统一用「训练层」指代被排除的训练动作)

### 推理资源层级(成本从低到高)

**本地推理**:
M1 MacBook Air(16GB)上用 Ollama 跑量化模型(qwen2.5:7b 等)。日常开发主力,边际成本 ¥0。
_Avoid_: 本地部署(我们不部署服务,只跑推理)

**免费 API 兜底**:
零成本云端 LLM(如智谱 GLM-4.7-Flash)。用于 demo 演示、本地跑不动时兜底。

**免费 GPU 平台**:
限时免费 GPU 的 Notebook 平台(魔搭 ModelScope、百度 AI Studio、Kaggle)。仅用于本地扛不住时的「救急重实验」,非日常开发(有上传 / 重配 / 断连摩擦)。

**付费 API**:
按 token 计费的云端 LLM(DeepSeek、通义)。免费额度用尽后的低价备选。

**付费租卡**:
按小时租用整张 GPU(AutoDL、Vast.ai 等)。**本计划排除** —— 唯一不可替代价值是「训练层」,而我们不训练。

## Relationships

- **应用层** 只消费推理,不触碰 **训练层**
- **付费租卡** 的存在理由是 **训练层**;**应用层** 用 **本地推理** + **免费 API 兜底** 即可覆盖
- **免费 GPU 平台** 与 **付费租卡** 都提供 GPU,但前者免费、有摩擦,仅救急;后者按小时付费,本计划不用

## Flagged ambiguities

- 「训练」已澄清(用户确认 B):指 (B) 跑实验练手(属 **应用层** 日常),非 (A) 微调权重(**训练层**,排除)。结论:**免费 GPU 平台** 不进必备清单,仅作偶发救急;**付费租卡** 排除。
- 「跑通本地模型」非学习前提:RAG/Agent 链路逻辑与调 API 完全相同(仅差 `base_url`)。本地的价值在零成本调试 + 推理工程体感 + 私有化作品卖点,而非"否则学不会"。一旦阻塞主线即切 **免费 API 兜底**。
