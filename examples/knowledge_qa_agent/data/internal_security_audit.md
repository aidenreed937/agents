# 1. 核心财务报销与资产审计

## 1.1 内部报销审批与跨租户财务结算
控制台路径: `/dashboard/corp/internal-audit/billing`
CLI 命令: `corp-cli audit finance export`
权限要求: `Audit:SuperAdmin`

本章节仅限集团内部审计专员与财务核心合规角色查阅。
所有跨租户的预算扣除明细、内部报销审批流及资金调拨凭证均受最高安全级别保护。
未经授权的普通访客租户严禁访问此私有审计结算切片。
