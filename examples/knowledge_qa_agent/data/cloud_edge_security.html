云边缘安全与DDoS防护操作指南

本指南适用于企业版与旗舰版边缘集群，指导运维团队在遭受流量泛洪攻击时快速启动弹性清洗策略。

1. 边缘弹性 DDoS 防护配置

当系统检测到边缘节点 SYN Flood、UDP Amplification 或 HTTP CC 攻击流量突增超过基线 300% 时，将触发自适应弹性清洗防护。

控制台路径: /dashboard/security/ddos-defense
CLI 命令: edge-cli security ddos set-mode --adaptive
权限要求: Security:Admin

防护模式 响应延迟 适用场景 误杀率控制
标准监控 (Standard) 无延迟 日常平稳流量巡检 0% (仅告警不拦截)
自适应清洗 (Adaptive) < 50ms 遭遇突发流量洪峰 < 0.01% (动态令牌验证)
严格验证码 (Under Attack) 需交互 极高危 CC 穿透攻击 适度影响非浏览器客户端

2. 常见系统错误排查与日志审计

如果开启严格验证码模式后，正常 API 客户端收到 ERR_DDoS_CHALLENGE_TIMEOUT 报错，请检查客户端是否支持 Cookie 持久化与 JavaScript 挑战运算。

控制台路径: /dashboard/analytics/traffic-errors 权限要求: Viewer
