# 电力设备预防性试验规程 (DL/T 596) - 变压器与充油设备绝缘篇

## 1. 规程总则与预防性试验周期
本规程规定了电力设备在运行、大修后及预防性试验中的电气绝缘检测项目、试验周期与合格判据。本标准适用于 110kV 至 750kV 交流油浸式电力变压器、并联电抗器以及互感器设备。
- 试验周期：110kV 及以上主变压器常规预防性试验周期为 1~3 年；处于重负荷或发生轻瓦斯报警等异常工况后应立即安排专项试验。

## 2. 油浸式变压器绕组绝缘特性基线标准
绕组绝缘电阻、吸收比（R60/R15）与极化指数（PI）是判断固体绝缘（绝缘纸）及变压器油是否受潮老化的核心电气参数：
1. **吸收比基线 ($R_{60}/R_{15}$)**：在常温 10℃~30℃ 下，吸收比不得低于 **1.3**；若低于 1.3，表明绝缘可能严重受潮或绝缘油劣化；
2. **极化指数基线 ($R_{10min}/R_{1min}$)**：对于 330kV 及以上大型变压器，极化指数不得低于 **1.5**；
3. **绕组介质损耗因数 ($\tan\delta$)**：在 20℃ 环境下，330kV~750kV 变压器绕组 $\tan\delta$ 不得大于 **0.8%**；220kV 变压器不得大于 **1.0%**。若实测值较历年同期增长超过 30%，应密切关注；
4. **运行绝缘油击穿电压基线**：330kV 设备运行油击穿电压不得低于 **50 kV**，500kV~750kV 设备不得低于 **60 kV**。

## 3. 互感器 (CT/PT) 与电抗器特征气体注意值 (强干扰对比)
不同类型充油电气设备因储油量与绝缘结构差异，特征气体注意值限值存在显著不同，**严禁将主变压器标准套用至互感器**：
- **电压互感器 (PT)**：总烃注意值基线为 **10 μL/L**，氢气注意值为 **150 μL/L**，乙炔不得检出（< 0.1 μL/L）；
- **电流互感器 (CT)**：总烃注意值基线为 **20 μL/L**，氢气注意值为 **150 μL/L**，乙炔注意值为 **1 μL/L**；
- **充油电抗器**：总烃注意值为 **150 μL/L**，乙炔注意值为 **1 μL/L**。

## 4. 油色谱产气与电气绝缘试验的交叉会诊规程
现场确诊严重设备隐患时，必须执行“色谱试验（DL/T 722）+ 电气绝缘试验（DL/T 596）”两路相互印证：
1. **绝缘纸严重受潮伴随局部过热（复合隐患）**：
   - 表现特征：色谱总烃超过 150 μL/L，同时电气试验中吸收比 $R_{60}/R_{15} < 1.3$，且绕组介损 $\tan\delta > 1.5\%$；
   - 确诊结论：表明变压器油纸绝缘系统内部不仅发生局部发热，而且主绝缘纸已严重受潮变质，水分破坏绝缘强度，击穿风险极高；
   - 应急处置决策：立即限制变压器出力，安排停电进行真空注油干燥或吊罩检修处理。
2. **放电故障与绝缘油劣化复合判据**：
   - 表现特征：色谱中检测出乙炔 C2H2 超标（> 5 μL/L），同时绝缘油击穿电压下降至 40 kV 以下；
   - 确诊结论：存在持续放电破坏绝缘油介电强度，必须立即申请紧急停运调度。

## 5. 新旧规程版本差异与现行有效版本 (版本仲裁)
- 历史废止版本：1996 年版规程曾允许 220kV 变压器介损 $\tan\delta$ 放宽至 1.5%；
- **现行有效版本 (DL/T 596 现行标准)**：明确废止历史放宽条款，严格执行 220kV $\tan\delta \le 1.0\%$、330kV~500kV $\le 0.8\%$ 的强制指标。凡涉及绝缘合格性裁决，必须以现行版最新指标为准。
