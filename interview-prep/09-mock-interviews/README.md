# 09-mock-interviews / 模拟面试与错题记录

## 模块目标
记录每次模拟面试、真实面试的实况录音要点、卡壳点与追问清单，驱动面试卡与笔记的针对性补丁。

## 记录规范
每次面试独立建档：`YYYYMMDD-[公司/模拟方]-[岗位].md`

## 模版结构
1. **基本信息**：日期、面试官角色、岗位定位（全栈 / Agent）。
2. **考察问题清单**：
   - 基础八股与原理深挖。
   - 算法/代码考核。
   - 系统设计/架构题目。
   - 项目经历深挖问题。
3. **卡壳与不满意点（直接证据）**：
   - 哪道题逻辑不严谨？
   - 哪个追问没有接住？为什么（知识盲区 vs 口述组织问题）？
4. **行动项（Action Items）**：
   - 需补充/修订哪几张面试卡？
   - 需要在实战项目中补充什么测试用例或代码验证？
