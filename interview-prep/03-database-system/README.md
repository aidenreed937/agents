# 03-database-system / 数据库与存储系统

## 模块目标
强化对关系型数据库、索引机制、事务隔离、向量检索扩展（pgvector）以及缓存一致性的掌控力。

## 重点课题
1. **关系型数据库（PostgreSQL / MySQL）**
   - 索引底层结构（B+ Tree 原理、覆盖索引、最左前缀原则）
   - 事务 ACID、四种隔离级别与对应并发问题（脏读、不可重复读、幻读）
   - MVCC 机制原理与锁分类（悲观锁、乐观锁、间隙锁）
   - 慢 SQL 定位与 Explain 执行计划关键指标分析
2. **向量数据库与扩展（pgvector）**
   - 向量检索核心原理与常用索引算法（IVFFlat vs HNSW 权衡与内存消耗）
   - 距离度量方式（Cosine、L2、Inner Product）适用场景
   - 混合检索（SQL 结构化过滤 + 向量相似度混合）的性能考量与隔离
3. **缓存系统（Redis）**
   - Redis 常见数据结构底层实现与业务适用场景
   - 缓存穿透、缓存击穿、缓存雪崩的成因与工程防护手段
   - 双写一致性方案（延时双删、Canal 监听 Binlog、异步补偿）
   - 分布式锁实现方案与 Redlock 争议
